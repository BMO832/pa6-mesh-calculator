# 양식장 그물 설계 계산기

기존 앱과 독립적인 새 Streamlit 앱입니다. 원본 `app.py`, `mesh_engine.py`, `v2`~`v5`는 수정하지 않습니다.

## 실행

저장소 루트에서 Python 3.10 이상으로 실행합니다.

```sh
python -m pip install -r aquaculture/requirements.txt
python -m streamlit run aquaculture/app.py
```

## Streamlit Community Cloud에 별도 배포

기존 앱의 설정을 변경하지 말고 **새 앱**을 만듭니다.

- Repository: `BMO832/pa6-mesh-calculator`
- Branch: `main`
- Main file path: `aquaculture/app.py`
- Python: 3.12 권장
- App URL: 기존 앱과 다른 주소를 선택

새 앱 경로 옆 `requirements.txt`는 기존 앱과 같은 Streamlit 1.66.1을 사용합니다.

## 기능

- 직교형·45도 회전형, 가두리 크기, 실 직경과 중심 간격.
- 전개 구간의 실 원주 표면적과 부착 불가율을 반영한 부착 가능 면적.
- 배양 사용률과 광 이용 비율을 별도 사용자 가정으로 표시.
- 수직 입사광 기준 수면 투영 차광면적·개구율·전체 가림률.
- 생물막 두께에 따른 유효 직경과 기하학적 막힘 변화.
- 길이 방향 전개율, 목표 가림률에서 중심 간격 역산, 간격별 비교.
- 실제 직경 비율의 격자 확대도, CSV/JSON 저장.

## 범위·가정

평면 면적, 원주 표면적, 부착 가능 면적, 투영 차광면적을 구분합니다. 고정 50% 매몰률은 적용하지 않습니다.

실 길이는 기존 앱 엔진의 직선 중심선·경계 규칙을 복사해 독립 사용합니다. 원형 실의 전체 원주 면적은 양면을 포함하므로 다시 두 배 하지 않습니다. 교차부·고정 손실은 사용자 입력 비율이며 자동 추정치가 아닙니다. 기본 0% 손실·100% 사용률은 미보정 비교 기준입니다.

직교형 차광은 경계로 자른 투영 띠의 합집합입니다. 회전형 차광은 무한 반복 격자의 면적비 근사여서 작은 패널·큰 간격에서 경계 오차가 생깁니다. 회전형의 실 표면적은 실제 사각 경계로 자른 중심선을 사용합니다. 모든 차광값은 불투명 실·수직 입사광 가정이며 광학 차광률·PAR·복사열·온도 저감의 측정값이 아닙니다.

전개율은 길이 방향으로 펼친 면적비입니다. 접은 부분은 가두리 밖에 보관하고 수면을 가리지 않는다고 가정합니다. 수면 위 접힌 그물 더미의 그림자는 모델에 없습니다. 생물막 두께는 차광에만 반영하며, 생물막 외측 표면 증가·산소 생산·유체 저항으로 환산하지 않습니다.

50% 목표 가림률은 조피볼락 최적 차광률이나 수온 감소 임계값이 아닙니다. 별도 불투명 차양층도 계산하지 않습니다. 실제 광학 차광·수온·산소·폐사 감소량·강도·접힘 내구성은 별도 검증이 필요합니다.

## 확인용 기준값

직교형 5×5m, 직경 2mm, 중심 간격 20mm, 100% 전개, 손실 0%, 생물막 0mm:

- 실 길이 2,510m, 원주 표면적 약 15.7708m².
- 기하학적 가림률 19%, 수면 투영 차광면적 4.75m².
- 전개율 50%이면 수면 전체 가림률 9.5%.

```sh
python -m unittest aquaculture.test_model
```
