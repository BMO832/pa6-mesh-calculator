## 구조·수치 규칙

C0 기본값: L=10 m, W=1.5 m, 날줄 3 mm, s=12 mm, 씨줄 1.2 mm,
N=20회/10 cm, 요철 1 mm, 리브 주기 5회, 경로계수 1.6, 굴곡계수 1.05,
밀도 1130 kg/m³, 회수율 60%, 심지 **외경** 0.15 m.

가닥수·실 길이·원통 면적·원통 체적은 지시문 식을 적용합니다.
리브는 일반 씨줄을 대체하며 중복 가산하지 않습니다.
`round(10*N*L)`는 Decimal 곱셈 후 정확히 절반일 때 짝수 정수로 반올림합니다.
격자는 V4의 경계 포함 중심선 규칙을 유지합니다. 회전 격자는 축별 매개변수 허용구간 교집합을 사용하며
특정 Liang-Barsky 구현이라고 주장하지 않습니다. 원점은 (0,0), 점 접촉은 길이 0으로 제외합니다.
실제 평직의 상하 교차·접촉·굴곡과 직선 격자 모델은 다릅니다.
회전형은 원사 사이 수직 틈만 표시하고 이를 진행 직각/진행 방향 틈으로 오인하지 않게 했습니다.

롤 지름은 π(D²-D_core²)/4=L*t로부터 유도합니다. 감김 공극·압축·장력은 미반영입니다.
짚신형은 기본/리브 두께로 각각 계산하며 실제 롤의 보장 범위가 아닙니다.
기존 격자의 롤 비교 두께 2d도 가정입니다.
R2는 사용자 실측 질량·표면적·유효 두께·틈을 받습니다. PA6 재질 확인 전에는 화학식을 적용하지 않습니다.
R2의 원료량은 같은 회수율을 적용한 가상 환산이며 시판 제품의 실제 원료 소요량이 아닙니다.

## 노출 구획·단위

- 전체 누적 용출 M = m_PA6*r/100*10^6 mg. 전체 질량 또는 M에 매몰률을 미리 곱하지 않습니다.
- 매몰부 면적 A_bur=A_total*f_bur, 비매몰 면적은 보조 출력입니다.
- 공극수 배분율 f_pw=f_bur*eta. 각 일일 신규 용출량에 **한 번만** 적용합니다.
- 분해 잔존량 R_pw=Σ ΔM_pw(j)*exp[-λ(t-j)], λ=ln2/H. 용출계수 k_i와 별개입니다.
- 경험식의 양의 초기 절편을 첫날 M(1)에 포함하고 일일 수지에서는 M(0)=0으로 둡니다. 날짜 말 투입입니다.
- 분해 미반영이면 R_pw=M_pw_in. 전체 잔존량 R_total도 별도로 보존합니다.
- 공극률 n=1-ρb/ρs, 부피 V_water=L*W*(z_cm/100)*n*S_w*1000 L.
- ρb<ρs, 비율 0-1 및 유한성 검사. 포화도 0%면 농도·최고·평균·비율은 None/공란이며 계산 불가로 표시합니다.
- C_pw=R_pw/V_water mg/L는 **전량 용존 가정의 공극수 환산농도**입니다.
- 최고는 1일부터 선택일까지 최대 날짜 말 농도(동률은 최초일), 평균은 같은 값들의 산술평균입니다.
- 포화도 25·50·100%와 선택 반감기/분해 미반영을 같은 구조·깊이·배분율로 비교합니다.
- V4 모래 지표는 **R_total/(ρb*A*z)** mg/kg dry sand입니다. 전체 잔존량을 쓰는 별도 대안 시나리오이며
  공극수 지표와 합산하지 않습니다. 모래 입자 흡착농도도 아닙니다.
- 각 깊이는 독립 완전혼합 시나리오이며 실제 수직 농도분포가 아닙니다.

## PNEC·문헌 확인

카프로락탐만 OECD SIDS의 수환경 PNEC 0.13 mg/L와 비교합니다.
OECD 원문 검색 색인에서 녹조류 Scenedesmus subspicatus EC50=130 mg/L,
평가계수 1000, PNEC=130 µg/L 도출 문장을 확인했습니다.
선택일·최고·평균 농도를 각각 0.13으로 나눈 참고 비율입니다.
달랑게류·긴꼬리도약옆새우류의 직접 독성 기준이 아니며, 염분·기간·종·경로가 다릅니다.
1 미만/초과로 안전 또는 피해를 판정하지 않습니다. 올리고머의 PNEC는 생성하지 않습니다.

출처 상세와 실제 제공 범위는 `sources.py` 및 오른쪽 패널에 있습니다.
기관 페이지 확인: ABA 1018.4·1018.6, NETZSCH 밀도 1.12-1.15 g/cm³, ANZG, EPA PDF, RollSpec.
Kansas State는 검색 색인 확인, 직접 페이지 접근 제한. SLU PDF는 기관 포털로 리디렉션되어 근거로 사용하지 않았습니다.
Peirce는 출판사 서지 확인, 원문 접근 제한. 클리핑 논문 DOI·서지 확인. 해당 참고문헌을 자체 구조식의 직접 출처로 오인하지 않게 표시했습니다.
14.4·37.6 cm의 대상종·원문·대표값 산정은 확정하지 못했으므로 출처 확인 필요로 표시합니다.
Fortmann 논문이 5·9.5·14일을 직접 제공했다고 검증되지 않아 실측값으로 표시하지 않습니다.
올리고머 반감기는 가상 민감도 분석입니다. 모든 링크가 해당 수치의 직접 검증을 의미하지 않습니다.

## 한계

1-64일은 문헌 실험 범위, 65-92일은 30°C 경험식 외삽입니다. 실제 해변 설치기간과 같지 않으며 최대 용출 보장값이 아닙니다.
올리고머 용출은 반정량, PA6 조각에서 모노필라멘트로 적용한 추정입니다.
밀도·매몰율·eta·포화도·리브·경로·굴곡·회수율은 실측 전 가정입니다.
공극수 구획에 배분된 물질이 모두 용해되어 균일 혼합된다고 가정합니다.
흡착·분배·용해도·침전·조석·강우·수분 이동·확산·유실·증발·수직 구배·굴 유입·체내흡수·전환 생성물은 모델링하지 않습니다.
소량의 물에 배분하면 계산농도가 과도하게 커질 수 있습니다. 실제 굴 내부 용존농도나 생물 흡수량이 아닙니다.
산술평균은 연속시간 시간가중 노출량이 아닙니다. 잔류 가정과 균일혼합의 효과가 달라 안전 상한이라고 부르지 않습니다.
