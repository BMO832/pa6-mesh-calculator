# PA6 Mesh Calculator V5 — 독립 추가 폴더

**설치:** 이 `v5/` 폴더를 기존 `BMO832/pa6-mesh-calculator` 저장소 루트에 복사하십시오. 기존 `v4/`와 `v3/`는 건드리지 마십시오. 독립 패키지는 `v4.mesh_engine`과 `v4.model.CHEMICALS`를 import하므로 **V5 폴더만으로는 앱이 실행되지 않습니다.**

```bash
python -m pip install -r v5/requirements.txt
python -m streamlit run v5/app.py
python -m unittest v5.test_v5 -v
python -m unittest v4.test_v4 -v
```

## 기능

- R1(기존 직교 격자), R2(시판 매트 입력), C0·A1-A4, 사용자 지정 짚신형 v2.
- PA6 원통 소재 질량, 리브 대체산정, 면적, 공극, 두께, 롤 직경, 원료 회수량.
- 0-100% 매몰률과 별도 0-100% 공극수 유입·유지율.
- V4의 5종 물질 계수를 재사용하는 30°C 1-92일 일일 투입/분해 계산. 65-92일은 원래 V4 범위(1-64일)를 벗어난 외삽.
- 공극률 = 1 - 건조 용적밀도 / 입자밀도; 0% 포화면 mg/L 없음.
- 선택일·최고일·산술평균 공극수 환산농도; 25%, 50%, 100% 포화도 비교 및 분해 미반영 대조.
- 독립 0-z cm 깊이 완전혼합 노출 시나리오, 카프로락탐 PNEC 참고비율, CSV.
- 좌우 2열 Streamlit UI, 10개 수식/근거 패널.

## 정확한 모델 경계

* PA6 전체 누적용출 `M_total`과 공극수 투입분 `M_pw=M_total*f_bur*eta`는 다릅니다.
* 일별 용출량을 먼저 배분하여 해당 투입일 이후 분해시킵니다. `M(0)=0`으로 정의하고 첫날 양의 절편분을 첫날 투입으로 처리합니다.
* `C_pw`는 물질이 모두 용해되어 균일하게 혼합된다고 가정한 **환산농도**로 실제 공극수 농도와 다릅니다.
* 별도 `mg/kg dry sand`는 **V4와 일치하는 전체 누적용출량의 모래층 총부하 시나리오**입니다. 공극수 농도 계산 잔존량과 합산하면 이중 계산이 됩니다. 공극수 구획이 별도로 정해진 점을 고려할 때 이 값은 모래 입자 흡착량도 아닙니다.
* 흡착·분배, 조석/강우, 이동·유실, 반응생성물, 분해/형상 온도의 변화를 계산하지 않습니다.
* 14.4/37.6cm는 생물종 및 인용·평균 최대 통계 원문 **확인 필요**.
* PNEC 0.13 mg/L는 사용자 지정 OECD 참고값으로 구현. 해당 원문에서 도출 경위를 독립적으로 재검증하기 전 교수용 자료에 검증된 값으로 단정하지 마십시오.
* 특정 1일말 값들의 단순 산술평균은 실제 시간가중 생물 노출량이 아닙니다.
* R2는 단일 직경 원통 모델 또는 사용자가 제공한 실측 질량·면적을 사용하며, 실측 표면적이 용출계수를 보정하지 않습니다.
* 미국 ABA Chapter 10의 1,525 mm는 beach access route의 clear width, 13 mm는 opening의 구 통과 기준으로, **법령 적용 여부 별도 검토**. 사용자 지정 6.5/10 mm는 내부 설계목표일 뿐입니다.
* 굴 깊이 계산은 깊이별 서로 다른 완전혼합 부피의 독립 시나리오이며 실제 수직 농도분포가 아닙니다.
* 회전 격자 구현은 V4 선분 클리핑 그대로이며 Liang-Barsky 알고리즘을 쓴다고 주장하지 않습니다.
* 직조 경로계수, 굴곡계수, 리브 형상, 회수율, 매몰률은 팀 가정으로 실측 필요.

## 근거

오른쪽 패널에는 A: 문헌경험식, B: 일반 기하·수학, C: 연구팀 자체 직조/경계 계산, D: 연구팀 가정으로 구분한 근거와 링크가 있습니다. 원문 링크는 사용자 지정 목록을 포함하지만 **모든 URL의 원문 전문과 수치가 별도로 독립 검증된 것은 아닙니다**.

별도 준비한 V4 계약 테스트 대역(mock: 사전 계수와 직교격자 계산) 환경에서 `v5.test_v5`의 5개 묶음 테스트 통과. 기존 리포지터리의 V4 전체 원본과 Streamlit은 현재 작업 실행환경에 없어서 `v4.test_v4` 회귀 테스트, V5 실제 UI/AppTest 및 화면 캡처는 아직 미실행입니다. 실제 저장소 안에서 위 명령으로 검증해야 합니다. 원본 V1-V4 파일을 수정하는 코드는 없습니다.
