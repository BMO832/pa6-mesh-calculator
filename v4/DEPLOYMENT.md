## 자동 검증

`python -m unittest v4.test_v4 -v`: **4개 테스트 통과**.

- 5종×4가지 반감기×64일 = 1,280개 시점의 유한성·비음수·질량수지 및 독립 감쇠 합산 검증
- 누적 용출량 비감소, 반감기와 잔존량 순서, 용출계수 k와 환경 분해계수 λ 분리
- V3의 두 직조 구조·PA6 질량 및 분해 미반영 카프로락탐 결과 일치
- 모래 계산 기준 사례와 단위·배율·잘못된 입력 거부
- 20개 유효 UI 설정에서 표·그래프·CSV·실시간 수식 결과 일치; 밀도 0 입력 시 오류 처리
- 기존 파일 24개의 SHA-256 일치
- 좁은 화면에서 패널을 위아래로 배치하고 긴 수식은 가로 스크롤 지원
