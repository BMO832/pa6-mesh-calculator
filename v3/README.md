# PA6 Mesh Calculator V3 — 로컬 실행 전용

V1 및 V2를 변경하지 않고 V2의 모양·기하학·질량·30°C 용출 계산을 복제한 별도 앱입니다.
원격 저장소에 업로드하거나 자동 배포하지 않았습니다.

## 실행

프로젝트 루트에서 PowerShell로 실행:

```powershell
.\.venv\Scripts\python.exe -m streamlit run v3/app.py --server.port 8503
```

브라우저에서 http://localhost:8503 를 엽니다. 기존 환경의 Streamlit을 사용하며 추가 설치는 없습니다.
새 환경에서는 `python -m pip install -r v3/requirements.txt`로 설치합니다.

## 새 계산

`sand.py`의 순수 함수 `calculate_sand(M_mg, A_m2, density_kg_m3, depth_cm)`를 사용합니다.

- h_m = h_cm / 100
- q_plan = M / A [mg/m²]
- V = A × h_m [m³]
- m_sand = ρb × V [kg dry sand]
- C = M / m_sand [mg/kg dry sand]

M은 V2의 mg 값을 변환 없이 받아 사용합니다. A는 매트 길이×너비이며 소재 표면적이 아닙니다.
50% 매몰을 질량에 다시 적용하지 않습니다. 모든 출력은 내부 반올림 없이 계산하며 CSV는 원래 정밀도로 저장합니다.
표와 곡선은 같은 순수 계산 함수로 생성합니다. 동일 깊이는 한 행에 표층·선택 표시를 합칩니다.
곡선은 1~130 cm 정수 지점에 표층·선택 깊이를 추가합니다. 0 농도에서 로그 선택 시 선형축으로 전환합니다.
CSV는 UTF-8 BOM이며 모든 행에 기간·온도·치수·면적·질량·밀도·구조·직경·간격·모델 가정을 포함합니다.

## 해석과 한계

이는 용출 질량 전량이 매트 아래 모래층 전체에 균일하게 혼합되는 **질량배분 시나리오**입니다.
30 cm는 0~30 cm층 평균이며 깊이 30 cm 지점의 농도가 아닙니다. 각 깊이는 독립된 대안이고 농도분포가 아닙니다.
ρb 기본 1500 kg/m³는 공극 포함 건조 용적밀도의 예시 가정값이며 방아머리 실측값이 아닙니다.
14.4·37.6 cm(달랑게 굴), 130 cm(갯방풍 뿌리)는 사용자 제공 참고값입니다.
저장소에서 해당 원문 출처를 확인하지 못했으므로 인용정보를 만들지 않았습니다.
이 깊이는 실제 오염 도달 깊이나 생물 평균 생활 깊이가 아닙니다. 130 cm는 탐색 상한입니다.

전량 잔류는 손실을 무시하지만 균일 혼합은 국소 고농도를 희석할 수 있으므로
**최대 노출농도·안전성을 보장하는 상한이라고 해석하지 않습니다.**
수중 용출 경험식을 모래에 배분하는 가정이며 실제 해변 방출량을 검증하지 않았습니다.
경험식 기간과 실제 설치기간은 자동으로 같지 않습니다. mg/L 수중 독성값과 mg/kg 모래 농도를 직접 비교할 수 없습니다.
강우·침투·지하수·확산·흡착·분해·생물흡수·체내농도·개체수 배분·위해지수·안전 판정은 모델링하지 않습니다.
