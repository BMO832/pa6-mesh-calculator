# PA6 Mesh Surface Area Calculator — MVP v0.1

폐어구에서 재생한 PA6 단일 원형 모노필라멘트 이동로의 기하학적 표면적을 계산하는 로컬 Streamlit 앱입니다. 외부 API를 사용하지 않으며 사용 통계 전송도 비활성화했습니다.

## 실행

Python 3.10 이상에서 프로젝트 폴더를 열고 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

이번 작업 환경에는 `.venv`를 준비했으므로 마지막 명령으로 실행할 수 있습니다. 설치 시에만 패키지 다운로드가 필요합니다. 직접 의존성은 Streamlit 하나이며 계산·SVG 미리보기·엔진 테스트에는 Python 표준 라이브러리만 사용합니다.

## 입력 및 출력

- 구조: 직교 격자형 / 회전 격자형
- 길이 L, 너비 W: m
- 직경 d, 중심 간격 s: mm (회전형에서는 인접 평행선 사이 수직 거리)
- 모든 입력은 유한한 양수, s > d여야 합니다.
- 출력: 평면면적(m²), 전체 필라멘트 길이(m), 매몰 전 표면적(m²), 50% 매몰 후 비매몰 표면적(m²)

계산 버튼을 누르면 결과 및 선택 구조의 2D 미리보기를 표시합니다. 입력을 바꾸면 계산 버튼을 다시 눌러야 합니다. 결과는 소수점 넷째 자리까지 표시하며 내부 결과는 반올림하지 않습니다. 매우 작은 양수 결과는 표시상 0.0000이 될 수 있습니다.

## 좌표와 경계 규칙

가로축 x는 L, 세로축 y는 W입니다. 매트는 닫힌 직사각형 `[0,L] × [0,W]`이며 좌측 하단 `(0,0)`이 고정 기준점입니다. 필라멘트 중심선이 경계 안에 있는 구간을 계산합니다. 경계와 일치하는 중심선도 포함하며, 꼭짓점 하나만 접하는 길이 0의 선분은 제외합니다. 실제 필라멘트 반지름으로 경계를 확장하거나 축소하지 않습니다.

### 직교형

d와 s를 m로 환산합니다. `y=k·s`와 `x=k·s`에서 k는 0 이상의 정수입니다.

```
Nx = floor(W/s) + 1
Ny = floor(L/s) + 1
전체 길이 = Nx·L + Ny·W
A_total = π·d·전체 길이
A_result = 0.5·A_total
```

Nx는 길이 방향 필라멘트 개수이고 Ny는 너비 방향 필라멘트 개수입니다. 반대편 경계는 간격의 정확한 배수일 때만 포함됩니다. 개수 계산은 입력의 십진수 표현을 정수비로 바꾸어 계산해, 예를 들어 `0.3/0.1`의 이진 부동소수점 오차로 경계 필라멘트가 빠지는 것을 방지합니다.

### 회전형

서로 직교하는 두 직선군을 사용합니다. k는 음수를 포함하는 정수이며 두 직선군 모두 k=0에서 원점을 지납니다.

```
(-x + y)/√2 = k·s     (+45° 방향)
( x + y)/√2 = k·s     (-45° 방향)
```

단위 법선 n을 사용하므로 평행선 사이의 수직 거리가 정확히 s입니다. 네 모서리를 법선에 투영해 후보 k 범위를 구하고, 각 직선을 직사각형에 매개변수 구간 방식으로 클리핑합니다. 각 선분의 유클리드 길이를 `math.fsum`으로 합산한 뒤 직교형과 동일하게 `πd` 및 `0.5`를 곱합니다. 경계의 수치 오차는 끝점을 경계 범위로 제한해 처리하며 임의의 양수 길이 절삭 허용오차는 사용하지 않습니다.

UI가 장시간 멈추는 것을 방지하기 위해 회전형은 후보 직선 200,000개까지 계산합니다. 초과 시 입력 조정을 안내합니다. 조밀한 격자 미리보기는 약 400개 중심선으로 샘플링하지만 계산은 모든 선분을 포함합니다. 미리보기의 선 굵기는 실제 직경이 아닙니다.

## 과학적 가정과 한계

- 원형 단면의 직선 원통 측면적만 계산하며 양 끝단 면적은 제외합니다.
- 교차부의 중복 표면적, 접촉면, 위아래 직조에 따른 실의 굴곡을 보정하지 않는 1차 근사입니다.
- 매몰률 50%는 전체 필라멘트 표면적의 절반이 가려진다는 이상화된 가정입니다. 실제 모래 접촉·매몰 형상을 계산하지 않습니다.
- 재생 PA6의 표면 거칠기, 기공, 손상, 직경 편차, 변형과 재료 물성은 반영하지 않습니다.
- UV, 물 노출, 카프로락탐 용출 및 3D 모델은 구현하지 않습니다. 결과는 용출량이나 환경 안전성을 예측하지 않습니다.
- 유한한 매트에서는 격자 방향, 간격, 경계 및 고정 기준점에 따라 총길이가 달라집니다. 두 구조가 항상 같은 표면적을 갖거나 회전형이 항상 작다고 일반화할 수 없습니다.
- Python 부동소수점 정밀도 한계가 있으며 수치 범위를 벗어나는 입력·결과는 오류로 처리합니다.

## 검증 및 동일 조건 비교

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

`test_mesh_engine.py`는 양수·유한값·s>d 검증, mm→m 변환, 직교 수식의 독립 계산, 정확한 경계 개수, 대각선·평행선·경계선·꼭짓점 클리핑, 원점 고정, 모든 끝점의 경계 포함 여부, 스케일 변화 및 미리보기와 계산의 독립성을 검증합니다. 회전형 독립 해석값으로 L=W=1 m, s=500 mm일 때 전체 길이 `5√2−3 m`도 비교합니다.

`test_app.py`는 Streamlit AppTest로 두 구조의 계산, 네 결과 및 SVG 생성, 잘못된 간격 입력 시 오류 표시와 기존 결과 제거를 검증합니다.

2026-10-26 검증 결과: Python 3.12.14 / Streamlit 1.66.1에서 엔진 12개 + UI 1개, 총 13개 테스트 통과. Windows 샌드박스에서는 AppTest의 로컬 소켓 생성이 대기하여 권한을 받아 샌드박스 밖에서 전체 테스트를 실행했습니다. 실제 브라우저의 시각적 배치는 별도 검증하지 않았습니다.

동일 조건: L=10 m, W=1 m, d=2 mm, s=20 mm.

| 출력 | 직교형 | 회전형 |
|---|---:|---:|
| 평면면적 (m²) | 10.0000 | 10.0000 |
| 전체 길이 (m) | 1011.0000 | 999.9985 |
| 매몰 전 표면적 (m²) | 6.3523 | 6.2832 |
| 50% 매몰 후 비매몰 표면적 (m²) | 3.1762 | 3.1416 |

이 조건에서는 회전형 비매몰 표면적이 직교형보다 약 1.0882% 작습니다. 직교형은 Nx=51, Ny=501로 경계 필라멘트를 포함합니다. 회전형은 경계에서 잘리는 길이가 달라 이 차이가 생깁니다. 넓은 영역에서 두 직선군의 단위 면적당 길이는 약 `2/s`이며, 이 근사값은 해당 예시에서 전체 길이 1000 m입니다. 이는 경계 효과를 설명하는 참고값이고 계산 엔진은 실제 유한 선분을 계산합니다.

- `app.py`: Streamlit 입력·결과·SVG 미리보기
- `test_mesh_engine.py`, `test_app.py`: 엔진 및 UI 테스트
- `requirements.txt`: UI 의존성
